TABLE 1. GLOSSARY (Term: meaning; code name)
==================================================================
Present: the whole nested object a run is about, one per run; code=Present
Layer: one wrapping shell: paper, ribbon, bubble wrap, foil, chains, ice, or a box. Layers nest from outside in.; code=Layer, LayerType
Overlay: tape strips laid over a layer's seams; each strip is its own panel with action Cut; a strip blocks the panels it spans until cut; tape is the only overlay.; code=Overlay, TapeStrip
Panel: one tearable piece of a layer; a paper layer is a grid of panels; a box lid is one panel; code=Panel
Depth: how many layers deep the team is; depth 0 is the outside; code=depth
Nest: the ordered list of layers in this present, generated at run start from a seed; code=Nest, seed
Tool: what the player holds; each tool has an action set and a grade; code=Tool, grade
Grade: a tool's strength, Grade 0 hands to Grade 3 chainsaw; code=grade
Action: Tear, Cut, Snip, Pop, Chip, Lift; each layer type accepts exactly one; code=Action
Side-gift: a loot item dropped by a layer, has a rarity, goes to the run bag; code=SideGift
Core gift: the item at the center of the present, one per run, rolled on the server; code=CoreGift
Run bag: loot held during a run, lost on a wipe, banked at the end; code=RunBag
Shelf: a player's persistent display of banked gifts in the lobby, stealable; code=Shelf
Index: the player's record of every gift type ever found, never loses entries; code=Index
Tick: a small ticking side box in one layer of the nest; opening it starts the Night; blocking=true means it is fused across the lid seam; code=TickBox
Night: the phase after the Tick opens, until the entity is shut or the team reaches the core; code=NightPhase
Jack: the entity released by the Tick, hunts the team during Night; code=Jack
Naughty: a per-player meter raised by stealing, decays daily, Krampus targets by it; code=naughty
Krampus: lobby-side entity that visits at lobby night and takes from the naughtiest shelves; code=Krampus
Tier: prestige level only, Birthday=1, Christmas=2, Wedding=3, The Package=4 (then The Package +1, +2, ...); sets layer count and loot table; code=tier
Wipe: all players in a run down at once; run bag lost, present gone; code=Wipe
Bank: converting the run bag to shelf and index at run end; code=Bank
Class: a perk set; a player owns every class they have rolled and picks one before a run; code=Class
Cash: run currency, buys tools and upgrades; code=cash
Gems: meta currency, buys class spins and cosmetics; code=gems

TABLE 2. PLAYER JOURNEY, FIRST SESSION (minute; what happens; what the player learns)
==================================================================
0:00; Spawn in the lobby facing the Start a Run pads. A present on the porch is already half torn, paper on the ground. One prompt: step on a pad.; Learns: this is a game about tearing presents open.
0:20; Teleport to the run room. A present fills the view. Hands are the tool. Tap and hold a panel: it rips, paper flutters, cash counter ticks.; Learns: the Tear, one thumb, no tutorial text.
1:00; First layer gone. Ribbon on the box underneath. Hands cannot cut it; a scissors pickup glows beside the present.; Learns: layers need the right tool; tools come from the room and the shop.
2:00; First box lid lifts with a sound sting. Two side-gifts drop and fly into the run bag with a rarity flash.; Learns: the Reveal; loot comes from layers.
4:00; A box deeper in the nest is ticking. The team can route around it or open it. A new player opens it.; Learns: the Tick; something is wrong with this present.
4:30; Jack is out. The team has 90 seconds of hide-or-shutter while continuing to tear. One player goes down; the others keep going.; Learns: the Night; death is not the end of the run.
7:00; Core box. The whole team lifts the lid together. The core gift rolls on screen. First run is seeded to land Uncommon, never Common.; Learns: the core gift is the reason to run again.
7:30; Bank screen: run bag to shelf and index, gems earned, class spin offered. Teleport to lobby.; Learns: progress persists; gems buy spins.
8:00; The shelf in the lobby now shows the core gift. Another player walks past it. A prompt: Naughty players can tear into your shelf, and Krampus takes from Naughty players.; Learns: steal exists and it has a cost.
9:00; Rewards booth for the daily, Classes booth for the spin, pad again.; Learns: the loop is closed.
Second session: first prestige prompt after three completed runs. Third session: player first sees Krampus take from a shelf that is not theirs.

DIAGRAM A. SYSTEMS ARCHITECTURE
==================================================================
Rule: the server decides everything; the client asks and animates. No client can change a number.

SERVER SYSTEMS (ServerScriptService), 8:
  Lobby: pads, party, teleport; rewards and class booths; lobby night clock
  Present: seed and Nest generation; layer table; Tick placement
  Tear: panel bitfields; validates each tear  [the highlighted system: every other run system waits on it]
  Night: Tick, Jack AI; downs and revives
  Data: ProfileStore; schema, migration
  Economy: cash, gems, shop; classes, prestige
  Loot: rolls, RunBag, Bank; Index, Shelf
  Steal: shelf tears, Naughty; Krampus takes

REMOTES (ReplicatedStorage.Shared.Remotes):
  Client to server: TearRequest, LidLift, ShopBuy, ClassSpin, StealRequest, Revive, BankChoice, EconomyRequest, LobbyRequest
  Server to client: RunState, LootEvent, NightState, ShelfState, TearState, ProfileState

TWO PLACES (lobby place and run place):
  Pads teleport the party into a private reserved server of the run place.
  The run place accepts only players whose teleport data carries a valid party token issued by the lobby; anyone else is teleported to the lobby on join.
  The reserved server shuts down when its last player leaves.
  Rejoin: a party member who disconnects can rejoin the same run within 120 s; the reserved server access code is stored in the profile at teleport time; the lobby shows "Rejoin run (m:ss)". After 120 s the run continues without them and they bank nothing from it.
  Join anyone: waits up to 20 s to fill a team of 4, then starts with whoever is there.
  Krampus clock: per lobby server. Featured present: chosen by UTC calendar date, same on every server.

CLIENT SYSTEMS (StarterPlayerScripts), 4:
  TearInput: hold, rip line; sends TearRequest
  Debris: pooled torn panels; 40 live max
  HUD: cash, depth, Night; bank, shop, classes
  Shelf: lobby display; steal prompt, timer

EDGES (caller -> callee: meaning):
  Lobby -> Present: start run
  Present -> Tear: Nest
  Tear -> Night: Tick opened
  Lobby -> Data: profile (load on join)
  Tear -> Loot: layer cleared
  Steal -> Loot: shelf moves
  Loot -> Economy: cash, gems
  Economy -> Data: save
  Remotes -> Server: validated calls
  Server -> Remotes: state out
  Client -> Remotes: player asks
  Remotes -> Client: state in

DIAGRAM B. RUN FLOW (state machine)
==================================================================
RunState values: Lobby, Building, Unwrapping, Night, CoreLid, Reveal, Bank, Wipe
Every remote checks the current state before it does anything.

STATES:
  Lobby pad: party of 1 to 4
  Build Nest: server seed
  Unwrapping: tear, cut, lift  [where most of the run is spent]
  Core lid: team holds E
  Reveal: core gift rolls
  Night: Jack out, 90 s (scales to 150 s at The Package)
  Wipe: run bag lost  [the only way to lose the run bag]
  Bank: shelf and gems

TRANSITIONS:
  Lobby pad -> Build Nest: step on pad
  Build Nest -> Unwrapping: Nest sent to client
  Unwrapping -> Night: Tick opened
  Night -> Unwrapping: timer out
  Night -> Core lid: core lid reached before the timer runs out (Night ends)
  Night -> Wipe: all living players down at once
  Wipe -> Lobby pad: back to lobby, run bag lost, index keeps what was seen
  Unwrapping -> Core lid: last layer cleared
  Core lid -> Reveal: lid lifts (3 s shared animation)
  Reveal -> Bank: after the 3 s animation
  Bank -> Lobby pad: run bag to shelf, index and gems, then teleport
Note: the Tick is the only branch. A party that leaves a non-blocking Tick sealed (60% of nests) never enters Night and reaches the core with a smaller bag, because the Tick box drops the run's best side-gifts when opened.

TABLE 4. LAYER TABLE (Mechanics A). Weights per depth band; a type can repeat but never twice in a row.
==================================================================
Paper; action=Tear; tool grade needed=0 (hands); weight outer third=50; middle third=30; inner third=20; depth 0 is always Paper, never taped
Ribbon and bow; action=Snip; tool grade=1; outer=20; middle=20; inner=10; shape=two bands crossing around the layer beneath plus a bow: 8 segments (one per face each band crosses) + 1 bow = 9 panels; the layer beneath is visible but cannot be torn until the ribbon is cleared; no shell of its own
Bubble wrap; action=Pop; tool grade=0; outer=0; middle=20; inner=20
Foil; action=Tear; tool grade=0; outer=0; middle=15; inner=15
Chains; action=Cut; tool grade=2 (box cutter); outer=0; middle=5; inner=20
Ice; action=Chip; tool grade=2; outer=0; middle=5; inner=15
Box lid; action=Lift; tool grade=0, two players on tier 2 and above; outer=0; middle=15; inner=20; placement=always the last two layers of every nest, and at least one more in the middle third; notes=taped at tier 2 and above: 4 strips, one per side across the lid seam (N36)
Layer count by tier: Birthday=6; Christmas=9; Wedding=12; The Package=16
Present size by tier (depth 0, studs across): Birthday=16; Christmas=20; Wedding=24; The Package=28; core box=6; shells between shrink evenly (ribbon wraps the layer beneath and takes no step)
Tick placement: a side box, side-gift sized, same paper as its layer, in a layer at a random depth in the middle third. blocking=false in 60% of nests (optional, beside the path); blocking=true in 40% (fused across that layer's lid seam; the lid cannot lift until the Tick is opened). Opening it starts the Night and drops the run's best side-gifts.
Panels: panels per face = clamp(floor(layer studs / 4), 3, 6), so a panel is about 4 studs (16-stud layer = 4x4 per face, 96 panels). Tape strips sit on seams and must be cut before the panels they touch can tear. The bottom face rests on the floor: its panels (and a ribbon's two bottom segments) are never interactive and fall away when the rest of the layer clears, so a 4x4 paper layer is 80 panels by hand and a ribbon 7 snips.
TAPE OVERLAY RULES: a Paper layer is taped with chance by depth band: outer third=40%; middle third=60%; inner third=80%; depth 0 never. A seam is a full grid line across a face (n-1 across and n-1 down: 6 per face and 36 per layer at 4x4). A taped paper layer tapes 25% to 50% of its seams, chosen from the seed (9 to 18 strips at 4x4). Each tape strip is one panel: action=Cut; tool grade=1 (scissors); seconds per strip=0.8 with scissors, 0.6 with box cutter, 0.3 with chainsaw. A strip runs its full line and blocks every paper panel it touches (8 at 4x4); a panel cannot be started until every strip touching it is cut. Strip width=1 stud. Tape is laid only on the five faces off the floor (the bottom face is never interactive). BoxLid layers are taped always at tier 2 and above, never at tier 1: 4 strips, one per side across the lid seam, same action, grade and seconds per strip as paper tape (N36); the lid cannot lift until its tape is cut. No other layer type takes tape.

TABLE 5. TOOLS (tool; grade; actions; seconds per panel; notes)
==================================================================
Hands; grade=0; actions=Tear, Pop, Lift; seconds per panel=1.2; notes=always equipped as fallback
Scissors; grade=1; actions=Cut, Snip, Tear at 1.0 s; seconds per panel=0.8; notes=first pickup, spawns beside the present the moment depth 0 clears

Tear feel spec: press-and-hold grows a tear line for the panel time, then release; early release keeps the rip line (progress never lost). On release: torn-edge mesh swap, small impulse away from the present, 2 s physics flutter, return to pool. Max 40 live debris per client, oldest recycled first. Audio: crinkle on hold start, rip on release, soft thud on landing; 3 variants each, pitch randomized within 10%. No camera shake on single panels; one 0.1 s shake on a chainsaw 2x2. One light haptic tap on release (mobile). Other players see the growing rip line.
Tear numbers set in the build (DECISIONS.md): reach=max(20, present studs + 4) from the character's server position, server-enforced (N37: Birthday 20, Christmas 24, Wedding 28, The Package 32; supersedes N21's 12); one holder per panel; the rip line keeps the first touch point. Debris: impulse=8 studs/s away from the present; spin=up to 4 rad/s per axis; gravity while fluttering=35%; after the 2 s flutter a piece settles where it lies and stays until recycled.
Greybox only, Phase 0–1 (DECISIONS.md): panel thickness=0.2 studs; Phase 0 checker=#A3A2A5 and #BDBCBF; Phase 1 paper=the layer's palette color checkered with the same color 15% toward white; tool pickup=2-stud white Neon block; HUD bar=#2B1E14, shop=#B98A52, buttons=#F2C230, toast 2 s; shop counter 6 studs in from its corner of the 60-stud run room; rip line=0.15 studs, #2B1E14; torn pieces keep their panel's color until a TornPanel mesh exists; present sits one present-width behind the origin.
