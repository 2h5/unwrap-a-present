## Premise

- Nobody has ever seen **the Sender**.
- Every present is addressed only **"To you"**.
- **The Tick** is the Sender checking whether you're still there.
- **The Package** tier is the Sender's present to itself.

## Rules for writing it

- One line per Secret, short enough to read on a phone in one glance.
- Never answer the whole mystery. Each line should raise one new question.
- No licensed characters or brands (invariant 2). Krampus is fine; the Sender is not Santa.
